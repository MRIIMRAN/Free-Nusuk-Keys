# 🕌 Nusuk Umrah Challenge Referral Codes

Free Nusuk referral codes (NG codes) for the Umrah Challenge. Use these codes to get +1 Key for Umrah draws in the Nusuk app!

## 🎯 About This Project

This website provides a collection of community-shared referral codes for the Nusuk Umrah Challenge. Each valid code gives you an extra key for a chance to win free Umrah trips through the Nusuk app.

## 📱 How to Use the Codes

1. Open the Nusuk Umrah Challenge app
2. Go to **"Start the Challenge"** → **"Keys"** → **"Add code"**
3. Browse codes in pages of 50
4. Click any code card to copy it instantly
5. Each successful code gives you +1 Key for Umrah draws

## 🚀 Deployment Options

### GitHub Pages (Recommended - Free + Custom Domain)

1. Go to `https://github.com/MRIIMRAN/nusuk-key-website`
2. In repository → Settings → Pages → Source → "main branch"
3. Your site will be at: `https://mriimran.github.io/nusuk-key-website/`
4. To use your custom domain `kylinbd.com`:
   - Add a `CNAME` file in the repo root containing: `kylinbd.com`
   - Configure DNS CNAME record pointing `www.kylinbd.com` to `yourusername.github.io`

### Google Sites

1. Create a new Google Site
2. Click "Insert" → "Embed"
3. Choose "Embed code" option
4. Paste the contents of `index.html`
5. Publish your site

### Netlify Drop (No account needed)

Just drag and drop the folder to: https://app.netlify.com/drop
